# George Egnatashvili - Web Developer Portfolio & Resume

A modern, high-performance, responsive personal resume and portfolio website built with pure Vanilla HTML5, CSS3, and JavaScript (ES6+).

## 🌟 Key Highlights & Features
- **GPU-Accelerated 3D Carousel**: Interactive 360° rotating 3D skill showcase powered by CSS 3D transforms, `perspective`, and hardware composition for 60-120 FPS performance.
- **Sub-Pixel Rendering Precision**: Clean, seamless black theme without visual seams or scaling artifacts across all zoom levels and display resolutions.
- **Cinematic Background Slideshow**: Smooth crossfading background hero slider utilizing hardware-accelerated opacity transitions.
- **Dynamic Typewriter Effect**: Custom character-by-character typewriter animation triggered when scrolled into view.
- **Featured Real-World Experience**:
  - **Hotel Digital Bar Menu & Real-Time Admin Panel**: Boosted seasonal bar sales by +40%.
  - **Custom CRM Architecture**: Scalable data models, pipeline tracking, and operational automation.
- **Mobile-First Responsive Design**: Optimized across mobile phones, tablets, laptops, and ultra-wide screens.
- **Zero Heavy Dependencies**: Built purely with native web technologies without jQuery or bloated libraries.

## 🛠️ Tech Stack
- **HTML5**: Semantic markup, accessibility, lazy-loaded media
- **CSS3**: CSS Custom Properties (Variables), 3D Transforms, Flexbox, Grid, Glassmorphism
- **JavaScript (ES6+)**: `IntersectionObserver`, `requestAnimationFrame`, modular event handling
- **Typography & Icons**: Google Fonts (`Outfit`, `Plus Jakarta Sans`), FontAwesome 6

## 🚀 Getting Started Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/maxstylee/My-CV.git
   ```
2. Open `index.html` directly in any modern web browser, or serve it using a local dev server:
   ```bash
   npx serve .
   ```
